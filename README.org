#+TITLE: Emacs Configuration Overview
#+AUTHOR: Nathan Martins Cunha


A literate, modular Emacs configuration inspired by Doom Emacs but built on vanilla =use-package= with Nix-based package management. The config lives in =~/.config/emacs/= as a collection of Org files that tangle to their =.el= counterparts on save.

* Architecture

The entry point is =config.org=, which =#+include:=s every module and provides the tangle+load bootstrap. Each module tangles to an =.el= file and is loaded in dependency order.

| Module          | Tangle Target    | Purpose                       |
|-----------------+------------------+-------------------------------|
| =config.org=    | =config.el=      | Root orchestrator             |
| =core.org=      | =core.el=        | Foundation: paths, defaults   |
| =ui.org=        | =ui.el=          | Evil, undo, window management |
| =theme.org=     | =theme.el=       | Fonts, doom-modeline, icons   |
| =completion.org=| =completion.el=  | Vertico-Corfu-Orderless stack |
| =tools.org=     | =tools.el=       | LSP, Magit, Treemacs, etc.    |
| =bindings.org=  | =bindings.el=    | SPC-leader keybindings        |
| =notes.org=     | =notes.el=       | Org mode, Org-roam, Markdown  |
| =containers.org=| =containers.el=  | Docker/Podman, Kubernetes     |
| =ai.org=        | =ai.el=          | gptel LLM chat                |

* Package Management

All elisp packages are declared as =use-package= forms in the =.org= modules. The Nix parser (=emacsWithPackagesFromUsePackage= with =alwaysEnsure = true=) discovers them automatically.

=extraEmacsPackages= in the Nix module covers only =jinx= (disabled spell-check, kept for future re-enable) — the one package the parser cannot discover.

* Key Features

** Doom-Style Leader Key

All primary commands are behind a =SPC= leader, with which-key labels. The leader map is defined in vanilla Emacs keymaps and bound into Evil's normal/visual/motion states.

** Completion System (Vertico Stack)

- =vertico= — vertical minibuffer completion with directory navigation
- =orderless= — space-based fuzzy matching with style dispatchers (=!=, =&=, =%=, ===, =^=, =~=)
- =marginalia= — rich annotations in the minibuffer
- =consult= — enhanced commands (=consult-buffer=, =consult-line=, =consult-ripgrep=, =consult-flymake=)
- =embark= — contextual actions on any completion candidate
- =corfu= — in-buffer IntelliSense-style popup (auto-triggered)
- =cape= — completion backends stacked with LSP taking priority, then file, dabbrev as fallback
- =nerd-icons-completion= + =nerd-icons-corfu= — icons everywhere

** LSP Support

Managed through =lsp-mode= with Nix-provided servers:

| Language       | Server                   |
|----------------+--------------------------|
| Python         | =basedpyright=           |
| Nix            | =nixd=                   |
| QML            | =qmlls=                  |
| Java           | Eclipse JDT.LS           |
| JS/TS/TSX      | =typescript-language-server= |
| HTML/CSS/JSON  | =vscode-langservers-extracted= |
| YAML           | =yaml-language-server=   |
| Dockerfile     | =dockerfile-language-server= |
| SQL            | =sqls=                   |
| C/C++          | =clangd= (via clang-tools) |

Tree-sitter grammars are also Nix-managed (=treesit-grammars= link farm), avoiding runtime compilation.

** Smart TAB

A Doom-style dispatcher: Minibuffer completion → Tempel snippet → Corfu popup → Magit section toggle → standard indentation.

** Smart K (Documentation Lookup)

Context-aware: =describe-symbol= in elisp, =lsp-describe-thing-at-point= under LSP, =evil-lookup= fallback.

** Project-Aware Run

=my/run= (async) and =my/run-compile= (compile buffer) detect mise tasks, npm scripts, Makefile targets, Gradle tasks, and Docker Compose commands. Completion is available in minibuffer prompts and inline in shell/terminal buffers via cape integration.

** Java Development

- IntelliJ-style class creation (=SPC c j=): new class, interface, enum, record, annotation
- Generate toString, equals/hashCode, overrides, accessors (=SPC c j g=)
- Extract variable, method, constant (=SPC c j x=)
- Source/test file navigation (=SPC c j T=)
- JaCoCo coverage visualization with inline lenses and missed-line highlights

** Git (Magit)

Full Magit integration with evil-collection keybindings, =git-timemachine= for history browsing.

** Org Mode & Notes

- =org-roam= for Zettelkasten note-taking (=~/org/=)
- =org-modern= for prettified buffers (custom stars, list bullets, tables)
- =ob-mermaid= and =ob-sql= for literate diagrams and SQL
- Auto-tangle on save for all config Org files
- =variable-pitch-mode= with monospace code/table faces
- Markdown mode with =gfm-mode= for README files

** Terminals

- =eat= — feature-rich terminal emulator with Solarized Light ANSI palette
- =vterm= — native terminal fallback (requires cmake/make/cc)

Both use =zsh= as the shell.

** Containers

-=docker= and =kubernetes= TUI packages configured for Podman (rootless socket).

** AI

-=gptel= configured for the MiMo API (Xiaomi token plan) with auth via =~/.authinfo.gpg=.

** Theme

Uses Rosé Pine (Dawn light / Moon dark) loaded from local theme files. Theme selection is synchronized with =noctalia= via =~/.config/noctalia/.darkmode=.

Fonts: Atkinson Hyperlegible Mono (coding) and Lexend (proportional reading), with Symbol/Emoji Nerd Font fallbacks.

** Undo System

-=undo-fu= + =undo-fu-session= for persistent linear undo across restarts
-=vundo= for graphical undo-tree visualization

** Formatting (Apheleia)

| Language     | Formatter          |
|--------------+--------------------|
| Python       | ruff (check+format)|
| JS/TS/TSX    | prettier           |
| HTML/CSS     | prettier           |
| C/C++        | clang-format       |

** Environment (envrc)

Per-project =direnv= integration via =envrc=, supporting both Nix flakes and mise projects.

* Nix Infrastructure

The Home Manager module (=dotfiles/modules/emacs.nix=):

- Uses =emacs-unstable-pgtk= with native compilation, Tree-sitter, SQLite3, and WebP support
- Provides 18 Tree-sitter grammars from Nix to avoid runtime compilation
- Supplies LSP servers and runtime tools isolated to the daemon PATH
- Generates =init.el= and =early-init.el= from Nix templates with variable substitution
- Systemd socket activation starts the Emacs daemon on first =emacsclient= connection
- =custom.el= is bootstrapped via activation script so it remains writable (not a store symlink)

* Notable Design Decisions

- No external completion frameworks — everything built on the Vertico-Corfu-Orderless-Consult stack
- No company-mode; Corfu replaces it entirely
- No flycheck; Flymake (with consult-flymake integration) is used instead
- Evil =jk= escape is implemented from scratch (no key-chord package)
- =visual-wrap-prefix-mode= (Emacs 30 built-in) replaces adaptive-wrap
- Spell checking (jinx) is disabled but wired for easy re-enable
- DAP mode is temporarily disabled for Java debugging

* Project Conventions

- =~/.config/emacs/= is a =git= repository
- Any file change requires: =nix flake lock --update-input emacs-config && home-manager switch=
- GPG signing is disabled for commits in headless environments
- =custom.el= holds safe local variables and is not version-controlled
