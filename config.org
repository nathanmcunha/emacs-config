* Undo System
Nós usamos uma combinação de três pacotes para a experiência suprema de desfazer:
1. ~undo-fu~: Wrapper linear simples para o sistema de desfazer do Emacs (necessário para o Evil).
2. ~undo-fu-session~: Salva o histórico de desfazer no disco (persistência entre reinícios).
3. ~vundo~: Visualizador gráfico da árvore de desfazer (para quando você se perde nos undos/redos).

#+begin_src emacs-lisp

Configures additional completion backends and the specific TAB integration strategy.

#+begin_src emacs-lisp
  (use-package cape
    :ensure t
    :init
    ;; Add `completion-at-point-functions`, used by `corfu`.
    ;; Note: We omit 't' (append) for cape-file so it takes precedence over normal code completion.
    (add-to-list 'completion-at-point-functions #'cape-file)
    (add-to-list 'completion-at-point-functions #'cape-dabbrev t)
    (add-to-list 'completion-at-point-functions #'cape-keyword t)

    :config
    (setq pcomplete-ignore-case t)
    (setq cape-dabbrev-check-other-buffers t)

    ;; --- Custom Tab Handling Strategy ---
    ;; This function tries to expand a snippet first.
    ;; If no snippet is available, it falls back to indentation (or completion if we were to bind it inside corfu-map).
    (defun my/yas-try-expand-first ()
      "Try to expand a yasnippet. If failed, indent the line."
      (interactive)
      (unless (and (bound-and-true-p yas-minor-mode)
                   (yas-expand))
        (indent-for-tab-command)))

    ;; Bind TAB globally to our custom function.
    ;; Note: When Corfu is open, corfu-map takes precedence, so TAB will navigate candidates
    ;; instead of expanding snippets. This is usually the desired behavior to avoid confusion.
    (global-set-key (kbd "TAB") 'my/yas-try-expand-first)
    (global-set-key (kbd "<tab>") 'my/yas-try-expand-first))

  (defun my/java-clean-signature (doc-string)
    "Limpa assinaturas Java para o ElDoc."
    (when (and doc-string (stringp doc-string))
      (let ((result (substring-no-properties doc-string)))
        (setq result (string-replace "&nbsp;" " " result))
        (setq result (string-replace "&lt;" "<" result))
        (setq result (string-replace "&gt;" ">" result))
        (setq result (replace-regexp-in-string "\\b\\(?:[a-z0-9_]+\\.\\)+\\([a-zA-Z_]\\)" "\\1" result))
        (setq result (replace-regexp-in-string "@[a-zA-Z0-9_]+\\(?:(.*)\\)?\\s-*" "" result))
        (setq result (replace-regexp-in-string "\\.\\.\\." "[]" result))
        (setq result (replace-regexp-in-string " throws .*" "" result))
        (setq result (replace-regexp-in-string "\\b\\(?:public\\|protected\\|private\\|static\\|final\\|native\\|synchronized\\|abstract\\|transient\\)\\b\\s-*" "" result))
        (setq result (replace-regexp-in-string "\\s-\\{2,\\}" " " result))
        (string-trim result))))
